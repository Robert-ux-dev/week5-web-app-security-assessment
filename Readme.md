# Week 5 – Web Application Scanning Tools & Proxying

**Project:** Automated Web Application Security Assessment for Financial Platforms  
**Internship:** JPR Solutions · Cybersecurity · Banking & Finance  
**Level:** Intermediate

---

## Overview

This repository contains the deliverables for **Week 5** of the internship project.

The focus of this week is to introduce and practice industry-standard web application security testing tools:

- **Burp Suite Community Edition** – for proxying and manual testing (Repeater, Intruder, etc.)
- **OWASP ZAP** – for automated vulnerability scanning

## Deliverables

| File | Description |
|------|-------------|
| `Week5_Web_App_Scanning_Tools_Report.docx` | Complete Week 5 report covering Burp Suite usage, OWASP ZAP scan results, and comparison of manual vs automated testing |

## Report Contents

1. Introduction & Objectives  
2. Burp Suite – Configuration & Manual Testing Summary  
3. OWASP ZAP Automated Scan (findings summary + full report reference)  
4. Comparison: Manual Testing vs Automated Scanning  
5. Conclusion & Lessons Learned  
6. Appendix (ZAP report and tool versions)

## How to Use

1. Download and open `Week5_Web_App_Scanning_Tools_Report.docx`.
2. Replace all placeholder text (shown in grey/italics) with your actual findings.
3. Insert screenshots of Burp Suite and OWASP ZAP.
4. Attach or link your full ZAP HTML/PDF report in the Appendix.

## Recommended Target Applications (for practice)

- OWASP Juice Shop
- DVWA (Damn Vulnerable Web Application)
- WebGoat
- Any deliberately vulnerable banking-style lab provided by the internship

> **Important:** Only test applications you are authorized to test.

## Tools Used

- Burp Suite Community Edition
- OWASP ZAP (Zed Attack Proxy)
- Modern browser (Firefox / Chrome) configured as a proxy client
